# SISTEM INVENTARIS BARANG

Aplikasi Sistem Inventaris Barang merupakan aplikasi untuk mengelola data inventaris, stok barang, barang masuk, dan barang keluar.

## Teknologi
- Frontend: JeasyUI Mobile
- Backend: PHP
- Database: MySQL
- Web Server: Apache (XAMPP)
- Version Control: Git dan GitHub
- Network: Wi-Fi LAN
- Communication: REST API

## Tujuan Proyek
Membangun sistem inventaris barang yang dapat digunakan dan diakses melalui jaringan lokal tanpa membutuhkan koneksi internet.
